# Bảo mật / Security

Kotoba Dojo hiện là ứng dụng web tĩnh, không có tài khoản, backend hoặc xử lý dữ liệu cá nhân tập trung.

Kotoba Dojo is currently a static web application with no accounts, backend, or centralized processing of personal data.

## Báo cáo lỗ hổng / Reporting a vulnerability

Không đăng công khai chi tiết lỗ hổng trước khi maintainer có cơ hội xử lý. Hãy dùng kênh liên hệ bảo mật được cấu hình trên repository hoặc liên hệ riêng với maintainer.

Do not publish vulnerability details before maintainers have had an opportunity to address them. Use the security contact configured on the repository or contact maintainers privately.

Khi báo cáo, hãy nêu bước tái hiện, tác động, trình duyệt/thiết bị và bằng chứng tối thiểu cần thiết.

Include reproduction steps, impact, browser/device details, and the minimum proof needed to understand the issue.
